# Дизайн-документ приложения «АвтоМастер»

**Система автоматизации автосервиса**

---

## 1. Тема проекта

**«АвтоМастер»** — комплексная веб-ориентированная система автоматизации операционной деятельности автосервиса. Приложение предназначено для малых и средних автосервисных предприятий, занимающихся ремонтом и техническим обслуживанием легковых и лёгких коммерческих автомобилей.

Продукт объединяет в едином цифровом пространстве процессы приёма заявок, ведения заказ-нарядов, управления складом запчастей, планирования загрузки механиков, расчёта стоимости услуг и взаимодействия с клиентами. Система доступна через веб-интерфейс и мобильную версию для сотрудников и клиентов.

---

## 2. Цель и задачи

**Цель проекта:**  
Повысить эффективность и прозрачность работы автосервиса за счёт автоматизации рутинных операций, снижения вероятности ошибок ручного учёта и улучшения клиентского сервиса.

### Основные автоматизируемые бизнес-процессы и решаемые задачи

1. **Приём и обработка заявок**
   - Онлайн-запись клиентов на ремонт/ТО через сайт или мобильное приложение.
   - Автоматическое распределение заявок по менеджерам.
   - Создание предварительного заказ-наряда на основе данных клиента и автомобиля.

2. **Ведение заказ-нарядов (рабочих листов)**
   - Электронная карточка заказа с полной историей: статусы, работы, запчасти, комментарии.
   - Контроль выполнения этапов ремонта (диагностика, согласование, ремонт, контроль качества, выдача).
   - Автоматический пересчёт стоимости при добавлении/удалении позиций.

3. **Управление складом и запчастями**
   - Учёт остатков запчастей на складе, автоматическое списание при использовании в заказе.
   - Уведомления о минимальных остатках, формирование заявок на закупку.
   - Подбор аналогов запчастей по каталогу (интеграция с внешними базами или внутренний справочник).

4. **Планирование загрузки персонала**
   - Календарь занятости механиков и постов.
   - Назначение ответственных исполнителей на заказ.
   - Контроль сроков выполнения работ, предупреждения о просрочках.

5. **Расчёты и документооборот**
   - Автоматическое формирование счетов, актов выполненных работ, товарных чеков.
   - Интеграция с кассовым ПО или встроенный модуль учёта оплат (наличные, карта, онлайн).
   - Ведение взаиморасчётов с клиентами (предоплата, постоплата, долги).

6. **Коммуникация с клиентом**
   - Автоматические уведомления о статусе ремонта (SMS/email/push).
   - Согласование дополнительных работ и запчастей через личный кабинет клиента.
   - Сбор отзывов и оценка качества обслуживания.

7. **Аналитика и отчётность**
   - Отчёты по выручке, загрузке мастеров, популярным услугам, расходу запчастей.
   - Анализ эффективности рекламных каналов записи.
   - Экспорт данных в Excel/1С для бухгалтерии.

## 3. Основные сущности (кто пользуется этим приложением и т.д.)

### 3.1. Роли пользователей (акторы)

| Роль | Описание | Основные функции в системе |
|------|----------|----------------------------|
| **Администратор (владелец)** | Владелец или управляющий автосервиса. Имеет полный доступ. | Настройка параметров системы, управление сотрудниками, тарифами и услугами, просмотр всех отчётов, управление складом, контроль финансов. |
| **Менеджер по записи / приёмщик** | Сотрудник, принимающий звонки и оформляющий заявки, встречающий клиентов. | Создание и редактирование заявок, запись на определённое время, предварительная оценка стоимости, согласование с механиками, выдача автомобиля. |
| **Механик / техник** | Исполнитель ремонтных работ. | Просмотр назначенных заказов, отметка о выполнении этапов, учёт использованных запчастей и времени, добавление комментариев и фото (при необходимости). |
| **Мастер-приёмщик (диагност)** | Специалист, проводящий первичную диагностику и определяющий перечень работ. | Создание сметы на основе осмотра, согласование с клиентом дополнительных работ, подтверждение технической возможности. |
| **Клиент** | Владелец автомобиля. Взаимодействует через веб-портал или мобильное приложение. | Онлайн-запись, просмотр статуса ремонта, согласование доп. работ и запчастей, оплата онлайн, история заказов, оставление отзывов. |
| **Бухгалтер (опционально)** | Сотрудник, отвечающий за финансовый учёт. | Выгрузка документов, сверка оплат, формирование отчётности для налоговой. |

### 3.2. Ключевые информационные сущности (объекты данных)

| Сущность | Назначение | Основные атрибуты |
|----------|------------|-------------------|
| **Клиент** | Физическое или юридическое лицо, владелец автомобиля. | ФИО/название, контакты (телефон, email), адрес, история заказов, бонусы/скидки, предпочтения. |
| **Автомобиль** | Транспортное средство, обслуживаемое в сервисе. | VIN, гос. номер, марка, модель, год выпуска, пробег, цвет, идентификатор клиента. |
| **Заявка (предварительная запись)** | Запрос клиента на обслуживание. | Дата/время желаемого визита, описание проблемы, выбранные услуги, статус (новая, подтверждена, отменена, выполнена). |
| **Заказ-наряд (рабочий лист)** | Основной документ, описывающий все работы и запчасти по конкретному обращению. | Номер, клиент, автомобиль, список работ, список запчастей, статус выполнения, ответственный механик, общая стоимость, даты начала/окончания. |
| **Услуга (работа)** | Стандартизированная операция с фиксированной или плавающей ценой. | Название, описание, нормо-час, стоимость, категория (диагностика, ТО, кузовной ремонт и т.д.). |
| **Запчасть** | Товарная позиция на складе или под заказ. | Артикул, производитель, наименование, цена закупки, цена продажи, количество на складе, минимальный остаток, совместимость с моделями авто. |
| **Сотрудник** | Работник автосервиса с определённой ролью. | ФИО, должность, график работы, ставка/процент, специализация, контакты. |
| **Складская операция** | Приход/расход/перемещение запчастей. | Тип операции, запчасть, количество, дата, ответственный, связанный заказ (если расход). |
| **Платёж** | Финансовая транзакция, связанная с заказом. | Сумма, способ оплаты, дата, статус, ссылка на заказ. |
| **Статус заказа** | Жизненный цикл заказа (справочник). | Новый, диагностика, ожидание согласования, в работе, готов к выдаче, выдан, отменён. |
| **Отчёт** | Аналитический документ, формируемый по заданным параметрам. | Тип отчёта, период, показатели, формат вывода. |

## Дополнительные замечания по функциональности

- **Интеграции:** система должна поддерживать обмен данными с бухгалтерскими программами (1С, Контур.Бухгалтерия), сервисами SMS-рассылок, онлайн-кассами (54-ФЗ), каталогами запчастей (TecDoc, Autodoc API).
- **Безопасность:** разграничение прав доступа на основе ролей, ведение журнала действий пользователей, шифрование персональных данных.
- **Мобильность:** адаптивный веб-интерфейс для всех ролей, возможность работы на планшетах механиков в цехе.
- **Масштабируемость:** архитектура, допускающая подключение нескольких филиалов автосервиса с единой базой клиентов и раздельным учётом складов.
